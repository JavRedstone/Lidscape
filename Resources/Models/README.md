# Optional local MacBook models

Apple USDZ files are not distributed in this repository. The app builds without them and uses its procedural laptop fallback.

For local use, place supported Apple USDZ assets in this directory. Filenames and rig mappings are in `Sources/Lidscape.swift`; source examples are in the root README. Rebuild after adding models.

These third-party files are excluded from the MIT license and ignored by Git. Download availability does not establish redistribution rights.
