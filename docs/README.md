# Lidscape guide

Lidscape adapts the iPhone Duo fold transition to a MacBook: the desktop changes perspective, blurs, and darkens as the lid moves, then can return to normal when you stop.

Start here:

1. [Install and enable Lidscape](getting-started.md) — Applications, Screen Recording, startup, and menu bar status.
2. [Try the preview](preview.md) — model selection, orbiting, zoom, playback, and angle modes.
3. [Tune the effect and calibration](settings.md) — hold reset, automatic calibration, blur, fade, and smoothing.
4. [Troubleshooting](troubleshooting.md) — permission loops, missing sensors, unexpected resets, and performance.

The screenshots show the current macOS app, cropped around the relevant controls. The preview uses the built-in Simple model, which is available without downloading Apple model assets. macOS permission-panel names can vary by system version.
