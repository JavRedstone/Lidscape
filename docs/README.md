# Lidscape guide

Lidscape adapts the iPhone Duo fold transition to a MacBook: the desktop changes perspective, blurs, and darkens as the lid moves, then can return to normal when you stop.

Start here:

1. [Install and enable Lidscape](getting-started.md) — Applications, Screen Recording, startup, and menu bar status.
2. [Try the preview](preview.md) — automatic Mac detection, orbiting, zoom, playback, and angle modes.
3. [Tune the effect and calibration](settings.md) — hold reset, calibration, appearance, lock-screen capture, and Activity history.
4. [Troubleshooting](troubleshooting.md) — permission loops, missing sensors, unexpected resets, and performance.

The screenshots show the current sidebar-based interface. Preview images may show optional local Apple model assets; release downloads use the built-in procedural fallback when those assets are unavailable. Activity screenshots use clearly labeled illustrative data. macOS permission-panel names can vary by system version.
